# SupKonQuest

Jeu de stratégie de conquête 2D multijoueur inspiré de Risk.

---

## Description

SupKonQuest est un jeu de stratégie au tour par tour où 2 à 8 joueurs s'affrontent pour conquérir une carte. Chaque joueur contrôle des camps, produit des unités et attaque ses adversaires pour dominer le territoire.

---

## Fonctionnalités

- 2 à 8 joueurs (humains ou IA)
- Carte 2D avec géographie variée : forêts, montagnes, murs, eaux
- Iles accessibles uniquement par bateaux
- Système économique : chaque camp génère de l'argent
- Production d'unités pour attaquer les camps ennemis
- Bonus pour posséder une région entière
- Au moins 3 cartes différentes disponibles

---

## Règles

- Chaque joueur commence avec le même nombre de camps
- Les camps produisent des unités à intervalles réguliers
- Un camp sans garde devient neutre si toutes ses unités meurent
- Un joueur perd quand il n'a plus de camps
